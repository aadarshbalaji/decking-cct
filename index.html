Netflix: Problem

Business Context

  • Netflix wanted to expand beyond passive streaming into interactive, choice-based storytelling experiences (e.g., Bandersnatch).
  • They needed a way to design, visualize, and validate deep narrative branches at scale—thousands of possible storylines, decisions, and endings.

Key Challenges

  • Narrative explosion problem: As choices multiply, storyline branches become complex, hard to track, and nearly impossible to test manually.
  • No internal tool to automatically generate, analyze, or visualize branching story paths.
  • Existing tools like Mermaid were not scalable — text-heavy, overloaded, poor zoom, unclear hierarchy, difficult for writers and product teams.

Our Solution: Intelligent Story Graph Generator

What We Built

  • Developed an AI-assisted system to generate narrative graphs from story scripts.
  • Parsed interactive story content into structured nodes: choices, outcomes, character states, and dependencies.
  • Built a graph visualization engine using Plotly to handle deep, wide branching structures with interactive filtering, zooming, and tooltips.

Key Features

  • Story node generation (choices, events, endings)
  • Auto-validation of loops, dead ends, and logical inconsistencies
  • Interactive, scalable visualization (Depth 4 → Depth 8 → Depth 12 graphs)
  • Better UI for writers and designers to collaborate.

System Architecture & Visualization

Business Value Delivered

Impact for Netflix Teams

  • Allowed Netflix writers, narrative designers, and product teams to instantly understand story complexity visually, not just in scripts.
  • Reduced manual testing time by 60% (dead-end detection, branch validation, logic flow).
  • Enabled easier A/B testing of user decisions and viewer engagement simulations.
  • Paved the way for dynamic story generation powered by user data, personalization, and AI-generated story variations.

Strategic Outcome

Helped Netflix scale interactive storytelling experiences—moving from one-off experiments to repeatable, scalable content production.

Autodesk: Problem

Business Context

  • Autodesk’s e-commerce platform was struggling to detect evolving fraud patterns for digital software purchases (subscriptions, renewals, bundled licenses).
  • Static rule-based fraud filters were brittle — fraudsters easily bypassed them using new devices, IP masks, and reused compromised cards.

Key Challenges

  • Rising Losses: Fraud-related losses and chargeback rates increased, especially in regions with reseller abuse.
  • Operational Bottleneck: High number of manual review cases slowed down checkout and hurt conversion.
  • Disjointed Signals: No unified system to combine behavioral, transactional, and device-level signals for real-time decisions.

Our Solution: ML-Powered Fraud Detection

What We Built

  • Designed an ML-powered fraud detection system with real-time scoring.
  • Feature Engineering: Built 60+ features across velocity, identity trust, account history, and transaction context.
  • Real-time Integration: Exposed as REST API microservice with <150ms latency at checkout.

Model Architecture

  • Supervised Model (XGBoost): Trained on labeled fraud/legit data to catch known patterns.
  • Anomaly Detector (Isolation Forest): Semi-supervised model to catch unseen/evolving fraud patterns.
  • Ensemble Risk Score: Combines probability + anomaly scores for a final decision.

System Architecture

Business Value Delivered

Impact

  • Reduced chargeback losses by over 40% through adaptive ML risk scoring.
  • Cut manual review workloads in half, allowing analysts to focus on high-confidence cases.
  • Improved checkout conversion by 3–4% by instantly approving low-risk customers.

Strategic Outcome

Enabled Autodesk to move from basic rules to a scalable fraud risk platform supporting multiple products and regions, laying the foundation for broader Trust and Safety infrastructure.

Meta: Problem

Business Context

  • Meta needed to improve scene-change detection for long-form video content (Reels, Watch, Ads).
  • Existing pipeline struggled with latency and compute efficiency at scale.

Key Challenges

  • Infrastructure Constraints: Traditional CV methods were not optimized for ARM-based infrastructure targeted for edge deployment.
  • Performance Bottlenecks: Lacked an efficient feature extraction and inference framework for high-throughput video segmentation.

Our Solution: Hybrid Scene Detection

What We Built

  • Redesigned the system for speed, accuracy, and hardware optimization.
  • Developed a hybrid statistics + ML model combining histogram variance, edge detection, and CNN-based shot boundary detection.
  • Built a streaming inference pipeline for chunk-based processing.

Key Optimizations

  • ARM Optimization: Quantized TensorFlow Lite/PyTorch models with NEON vectorization.
  • Efficiency: Minimized memory footprint and enabled parallel processing.
  • Integration: Real-time segmentation and metadata tagging for Meta's publishing system.

System Architecture

Business Value Delivered

Impact

  • Achieved 2.7× faster video processing speed on ARM-based infrastructure.
  • Reduced scene-detection compute costs by 38% due to quantization and batch optimization.
  • Enabled real-time content segmentation for Ads, Reels, and content moderation.

Strategic Outcome

Directly supported Meta’s video personalization and ad-placement initiatives by enabling efficient, scalable video analysis.
